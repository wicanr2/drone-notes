# 00 系統全景

無人機系統的分層不是慣例,是延遲預算算出來的結果。這一章把物理約束推成架構決策,再落成可檢驗的責任邊界。

| 篇 | 主題 | 回答 |
|---|---|---|
| [01](01-the-control-loop.md) | 為什麼無人機非得長成這個樣子 | 多旋翼為何靜不穩定、延遲怎麼吃掉相位裕度、各層迴路的延遲預算差幾個數量級 |
| [02](02-system-boundaries.md) | 責任邊界:一個功能該放在哪一層 | 三個判準、每層不負責什麼、五個常見的放錯案例、層間契約 |

讀完應該能回答:

- 為什麼姿態控制不能放在伴隨電腦上,而位置指令可以?
- 為什麼視覺定位不是「取代 EKF」而是「餵給 EKF」?
- 有人提議把避障放雲端,你要用哪個判準駁回?
- 任務進度的唯一真相來源在哪一層,為什麼不是雲端?
