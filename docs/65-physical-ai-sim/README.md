# 65 Physical AI 模擬環境

[60 章](../60-simulation-and-testing/)的模擬是為了**驗證**——擋回歸、重現故障。這一章的模擬是為了**訓練**——把策略學出來。兩者的需求幾乎正交,混為一談是建環境時最貴的錯誤。

專案狀態與授權以 `gh api` 於 2026-08-05 查證。

| 篇 | 主題 | 回答 |
|---|---|---|
| [01](01-training-stack.md) | 訓練堆疊與選型 | 訓練與驗證的需求對照、四層堆疊、Newton 1.0 與 Isaac Lab 的現況、四套無人機學習環境怎麼選、資料生成層的門檻、硬體需求 |
| [02](02-sim-to-real.md) | 從訓練到上機 | 訓練特有的保真度缺口、domain randomization 要隨機什麼、策略該放在哪一層、PX4 `mc_nn_control`、學習元件的四條安全規則、驗收與路線圖 |

讀完應該能回答:

- 為什麼訓練環境不能拿來當驗證環境?
- Aerial Gym 上手最快,為什麼長期產線反而該押 Isaac Lab?
- 一個學出來的策略,什麼情況下只能跑在飛控的 MCU 上?
- 把神經網路放進 1 kHz 的控制迴路,要先做好哪四件事?
- 獎勵曲線很漂亮,為什麼不代表能飛?
