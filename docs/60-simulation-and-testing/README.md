# 60 模擬與測試

模擬最大的價值不是像,是可重複。真機測試無法回答「這個修改到底有沒有讓情況變好」,因為環境每次都不一樣;模擬把這個變數消掉了。

| 篇 | 主題 | 回答 |
|---|---|---|
| [01](01-what-simulation-proves.md) | 模擬能證明什麼 | 模擬只換掉物理世界那一格、各項目的保真度差多少、哪些結論能外推哪些不能、怎麼縮小落差 |
| [02](02-gazebo-and-isaac-sim.md) | Gazebo 與 Isaac Sim | 兩者的架構與接 PX4 的方式、對照表、混合策略、六個實務上會踩的坑 |
| [03](03-ci-and-regression.md) | 建自動化驗證系統 | 情境即程式碼的格式、該斷言哪些指標、故障注入矩陣、執行架構、分層控制成本、處理不穩定測試、最小可行的七步 |

讀完應該能回答:

- 「已在模擬驗證」這句話,對哪些結論成立、對哪些不成立?
- 為什麼把 CI 建在 Isaac Sim 上是個壞主意?
- 只斷言「任務有完成」的測試會漏掉什麼?
- 測試偶發失敗時,為什麼不能直接加自動重試?
